# BETTIOUR SECURIA — Sito web

Sito statico pronto per GitHub Pages.

## File
- `index.html` — struttura e contenuti del sito
- `style.css` — grafica e responsive
- `script.js` — menu, FAQ, animazioni e invio modulo

## Modulo preventivo
Il modulo è già collegato a Formspree tramite l'endpoint fornito dal proprietario del sito.

Quando un visitatore invia il modulo:
1. i dati vengono inviati a Formspree;
2. la pagina non viene ricaricata;
3. viene mostrato un messaggio di conferma o errore.

## Pubblicazione su GitHub Pages
1. Crea un repository GitHub, ad esempio `bettieur-securia`.
2. Carica direttamente i tre file del progetto (`index.html`, `style.css`, `script.js`).
3. Vai in `Settings` → `Pages`.
4. Seleziona `Deploy from a branch`.
5. Branch: `main`, cartella: `/ (root)`.
6. Salva e attendi la pubblicazione.

Non caricare lo ZIP dentro il repository: estrai prima i file.
